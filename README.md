STUDENT REGISTRATION SYSTEM

A simple Student Registration System built using PHP, MySQL, and XAMPP.

## Features
- User registration form
- Email validation
- Password validation
- MySQL database storage

## Tools Used
- PHP
- MySQL
- XAMPP
- HTML

## How to Run
1. Install XAMPP
2. Place project in htdocs folder
3. Start Apache and MySQL
4. Open localhost/phppro/studentregistration.php

## Project Output
Successfully registers student details into database.
